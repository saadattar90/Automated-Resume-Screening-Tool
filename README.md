# 🤖 Automated Resume Screening Tool

## 🚀 Overview
An AI-powered Resume Screening Tool that automatically analyzes resumes and compares them with a job description using NLP and Machine Learning techniques.

The system extracts resume text, calculates similarity scores, ranks candidates, and generates shortlist decisions automatically.

---

## 📌 Features

✅ Resume Parsing  
✅ Job Description Matching  
✅ TF-IDF Vectorization  
✅ Cosine Similarity Scoring  
✅ Candidate Ranking  
✅ Shortlist/Rejection Decision  
✅ CSV Report Generation  
✅ Visualization Graphs
